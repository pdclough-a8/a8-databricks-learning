# Keep evidence, not just ticks

Copy this template into your own private note. The repository version is a template, not a learner record.
Do not commit workspace URLs, personal identifiers, credentials or raw provider logs into shared course material.

```text
Course version/release:
Route chosen:
Authorised workspace alias (not credentials):
Catalog / schema / learner tag:
Exact table / app / ownership marker:
Budget and stop rules:
Success statement:

Readiness: destination, data limits and stop procedure explained:
Lesson 1:
  Leeds query and expected/actual values:
  Manchester change:
  Under-ten gap:
  Bristol independent transfer:
  Why bookings are not a forecast:
Lesson 2:
  Endpoint alias and approved request count:
  Leeds expected / actual / IDs / verdict / reason:
  Manchester expected / actual / IDs / verdict / reason:
  Missing-policy expected / actual / verdict / reason:
  Simulation vs fixed context vs retrieval explained:
Lesson 3:
  Deployment status:
  Simulation supported and unsupported checks:
  Live app checks, or explicit blocker:
  Title change, restore and redeployment checks:
  Notebook identity vs app identity explained:
  Four-sentence handover and peer feedback:

Last checked checkpoint:
Pause: flags reset / app stopped / own compute stopped:
Final: table absent / app absent / source grant reviewed:
```

Use **followed**, **adapted independently**, and **explained** as different levels of confidence.
A copied working query is a useful starting point, not proof of transfer.
Return after a day and explain the data-to-answer path without looking, then check what you missed.
Mark blocked live stages as blocked. A simulation result must never become a live-model pass.

# An optional teammate

You can finish this course without an AI tutor or local tools.
If you use a workspace assistant, browser chat or coding assistant approved by your organisation,
give it the contract in `prompts/tutor.md`. Never send the internal brand playbook or private workspace data.

Try this starter:

```text
Act as my A8 learning tutor using the supplied tutor contract.
I'm on lesson 1, UI-led route. My query runs, but I don't understand why remaining is derived.
Explain the idea, ask me one prediction, then help me check it.
Do not deploy anything, call a model, change permissions or delete resources.
```

Give the lesson, route, expected result and a redacted symptom. Ask for a hint before a solution.
Supplied runnable code is welcome; understanding why it works still matters.
When you need a full solution, ask for it, then repeat the transfer task without copying.

AI help can be wrong. Check it against the course's evidence and current platform documentation.
The tutor must ask before billable operations and cannot certify that an untested deployment works.
Keep [your progress note](progress.md) as the handover between sessions and tools.
